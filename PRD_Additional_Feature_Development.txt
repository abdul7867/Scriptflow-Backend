## 1. Executive Summary

### 1.1 Product Vision
ScriptFlow is an AI-powered script generation tool that helps content creators "steal like an artist" by analyzing viral Instagram Reels and generating customized scripts based on the user's unique ideas.

### 1.2 Purpose of This Document
This PRD outlines the additional features and enhancements planned for ScriptFlow 2.x to improve user experience, increase engagement, and build a robust platform for future ML model training.

### 1.3 Key Objectives
- **Improve Script Quality**: Better language matching, tone consistency, and variation diversity
- **Enhance User Experience**: Cleaner copy interface, pro insights, personalization
- **Enable Learning Loop**: Build feedback mechanisms for continuous improvement
- **Scale Platform**: Performance optimizations and infrastructure improvements

## 3. Problem Statements

### 3.1 User Problems

**P1: "I don't know if my script is good until I film it"**
- Users have no way to preview how the script will feel before shooting
- No audio preview or TTS for dialogue

**P2: "I keep regenerating but get similar scripts"**
- Variation mode needs more creativity
- Users want more control over variation direction

**P3: "I want to save my favorite scripts for later"**
- No favorites/collection system
- No way to organize scripts by niche or style

**P4: "I want to learn what makes a hook work"**
- Metadata (Hook Type, Tone) is hidden or unclear
- No educational layer explaining the patterns

### 3.2 Business Problems

**B1: "We need more feedback data for model training"**
- Current feedback loop is minimal
- No granular section-level feedback

**B2: "We need to convert waitlist users to paying customers"**
- No monetization strategy implemented
- No premium tier differentiation

**B3: "We need to reduce API costs"**
- Some video analysis is redundant
- Caching could be more aggressive

### 4.2 Feature Specifications

#### FEATURE 1: Pro Insights Toggle

**Description**: Allow users to toggle visibility of script metadata (Hook Type, Tone, Visual Cues) for educational purposes.

**User Value**: 
- Creators learn why scripts work
- Helps them internalize patterns for future content

**Requirements**:
- Add toggle button on copy page
- Store preference in UserMemory
- Default: OFF for simplicity

**Acceptance Criteria**:
- [ ] Toggle appears on script view page
- [ ] Metadata section expands/collapses smoothly
- [ ] User preference persists across sessions
- [ ] Mobile-responsive design

---

#### FEATURE 2: Audio Preview (TTS)

**Description**: Allow users to preview how the dialogue sounds before filming.

**User Value**:
- Hear pacing and flow
- Catch awkward phrasing before shooting
- Especially helpful for non-native speakers

**Requirements**:
- Integrate TTS service (Google Cloud TTS / ElevenLabs)
- Generate audio for dialogue sections only
- Add play button next to each dialogue block
- Add "Play All" button for full script

**Technical Considerations**:
- Cache TTS audio in S3 to avoid regeneration
- Offer voice selection (male/female/accent)
- Keep audio files < 30 seconds for cost efficiency

**Acceptance Criteria**:
- [ ] Play button appears next to each dialogue
- [ ] Audio plays inline without page navigation
- [ ] Works on mobile Safari (autoplay restrictions)
- [ ] Voice quality is professional grade

---

#### FEATURE 3: Enhanced Variations (Variation Modes)

**Description**: Give users control over HOW the script should vary.

**User Value**:
- Instead of just "another", users can specify:
  - "Make it funnier"
  - "More controversial"
  - "Shorter hook"
  - "Story-based angle"

**Requirements**:
- Detect variation intent from message
- Pass variation mode to AI prompt
- Show variation mode in response

**Variation Modes**:
| Mode | Trigger Keywords | Effect |
|------|------------------|--------|
| Funnier | "funnier", "more funny", "😂" | Add humor, wordplay |
| Edgier | "edgier", "more controversial", "spicy" | More provocative takes |
| Shorter | "shorter", "tighter", "quick" | Reduce word count by 30% |
| Story | "story", "narrative", "personal" | Story-based structure |
| Data | "stats", "data", "facts" | Add statistics/proof points |

**Acceptance Criteria**:
- [ ] At least 5 variation modes work
- [ ] Mode is correctly passed to AI
- [ ] Script output reflects the requested mode
- [ ] User feedback confirms variation is noticeable

---

#### FEATURE 4: Script Collections

**Description**: Allow users to save, organize, and revisit their favorite scripts.

**User Value**:
- Build a library of proven scripts
- Organize by niche, topic, or performance
- Reference past scripts when filming

**Requirements**:
- Add "⭐ Save" button on script view
- Create Collection model in MongoDB
- API endpoints: save, list, delete, tag
- ManyChat flow: "Show my saved scripts"

**Data Model**:
```
Collection {
  subscriberId: string
  scripts: [{
    scriptId: ObjectId
    addedAt: Date
    tags: string[]
    notes: string
  }]
  maxScripts: number (limit: 50 for free, 500 for pro)
}
```

**Acceptance Criteria**:
- [ ] Save button works on copy page
- [ ] User can view list of saved scripts
- [ ] User can add tags to scripts
- [ ] Scripts persist across sessions
- [ ] Delete functionality works

---

#### FEATURE 5: Feedback Loop 2.0

**Description**: Collect granular, actionable feedback on generated scripts.

**User Value**:
- Influence future script quality
- Feel heard and engaged

**Business Value**:
- High-quality training data
- Understand what works per niche

**Requirements**:
- After script delivery, send feedback prompt
- Quick reactions: 👍 👎 ⭐ (loved it)
- Section-specific feedback: "Hook was weak" / "CTA was perfect"
- Track regeneration as implicit negative feedback

**Feedback Data Model**:
```
Feedback {
  scriptId: ObjectId
  subscriberId: string
  
  // Quick feedback
  overallRating: 'loved' | 'good' | 'bad'
  
  // Section feedback
  sections: {
    hook: { rating: 1-5, wasRegenerated: boolean }
    body: { rating: 1-5, wasRegenerated: boolean }
    cta: { rating: 1-5, wasRegenerated: boolean }
  }
  
  // Open feedback
  comment: string
  wouldFilm: boolean
  didFilm: boolean
  performanceScore: number (if they share metrics later)
}
```

**Acceptance Criteria**:
- [ ] Feedback prompt sent after script delivery
- [ ] Quick reactions captured
- [ ] Section feedback UI works
- [ ] Data stored correctly in MongoDB
- [ ] Feedback stats API returns aggregated data

## 5. User Stories

### 5.1 Pro Insights Toggle
```
AS A content creator
I WANT to see why my script's hook works
SO THAT I can apply the same pattern to future content

GIVEN I'm on the script view page
WHEN I tap "Show Pro Insights"
THEN I see Hook Type, Tone, and Visual Cues metadata
```

### 5.2 Audio Preview
```
AS A creator who struggles with pacing
I WANT to hear my script read aloud
SO THAT I can fix awkward phrasing before filming

GIVEN I'm viewing a generated script
WHEN I tap the play button next to a dialogue
THEN I hear the dialogue spoken in a natural voice
```

### 5.3 Enhanced Variations
```
AS A creator who wants more humor
I WANT to say "make it funnier"
SO THAT I get a variation with jokes and wordplay

GIVEN I received a script
WHEN I say "funnier" or "make it funny"
THEN I receive a new variation with added humor
```

### 5.4 Script Collections
```
AS A creator with many scripts
I WANT to save my favorites
SO THAT I can reference them later when filming

GIVEN I'm viewing a script I love
WHEN I tap the "Save" button
THEN the script is added to my collection
```

### 5.5 Pro Tier
```
AS A power user
I WANT unlimited scripts and premium features
SO THAT I can create content faster

GIVEN I'm a free user hitting rate limits
WHEN I see the "Upgrade to Pro" prompt
THEN I can subscribe and immediately access Pro features
```

### 6.2 New API Endpoints

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/v2/collections` | GET | List user's saved scripts |
| `/api/v2/collections` | POST | Save script to collection |
| `/api/v2/collections/:id` | DELETE | Remove script from collection |
| `/api/v2/tts/generate` | POST | Generate TTS audio for script |
| `/api/v2/subscription/create` | POST | Create Stripe checkout session |
| `/api/v2/subscription/cancel` | POST | Cancel subscription |
| `/api/v2/subscription/webhook` | POST | Handle Stripe webhooks |

## 9. Risk Assessment

### 9.1 Technical Risks

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| TTS service downtime | Low | Medium | Graceful fallback, show text only |
| Stripe webhook failures | Low | High | Retry logic, manual reconciliation |
| AI model degradation | Medium | High | Monitor quality scores, rollback prompt |
| Database scaling issues | Low | High | Add indexes, consider sharding |

### 9.2 Business Risks

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| Low Pro conversion | Medium | High | A/B test pricing, add value |
| User churn after trial | Medium | Medium | Improve onboarding, value delivery |
| Competitor copying features | Low | Low | Focus on execution, community |
| API cost overruns | Medium | Medium | Aggressive caching, usage alerts |

### 9.3 User Experience Risks

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| Feature overload | Medium | Medium | Keep defaults simple |
| Audio quality complaints | Low | Medium | Use high-quality TTS provider |
| Payment confusion | Low | High | Clear pricing, easy cancel |

## 10. Appendix

### 10.1 Competitive Analysis

| Competitor | Strengths | Weaknesses | ScriptFlow Advantage |
|------------|-----------|------------|---------------------|
| ChatGPT | Generic, powerful | No video analysis | Reel-specific DNA extraction |
| Jasper AI | Marketing focus | Expensive, no video | ManyChat integration, cheaper |
| Copy.ai | Easy to use | Template-based | Creative "stealing" approach |

### 10.2 User Personas

**Persona 1: Aspiring Creator (25-35)**
- Posts 3-5 reels/week
- Struggles with hook ideas
- Wants proven formulas
- Price sensitive

**Persona 2: Marketing Agency (Team)**
- Creates content for clients
- Needs volume and consistency
- Willing to pay for efficiency
- Values organization (collections)

**Persona 3: Personal Brand Builder**
- Focused on one niche
- Wants to sound authentic
- Uses for inspiration, not copy-paste
- Values learning (pro insights)

### 10.3 Glossary

| Term | Definition |
|------|------------|
| **Hook Type** | The psychological pattern used in the first 3 seconds (e.g., Question, Controversy, Pattern Interrupt) |
| **Reel DNA** | Extracted characteristics of a reference video (transcript, tone, visual cues) |
| **Variation** | A new version of a script with different hook/angle but same idea |
| **TTS** | Text-to-Speech - converting script text to audio |
