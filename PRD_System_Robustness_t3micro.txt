## Executive Summary

This PRD outlines a comprehensive system robustness initiative for ScriptFlow to ensure **zero-crash operation** on AWS t3.micro instances while supporting **100 concurrent users**. This document **complements** the Performance Optimization PRD and focuses on reliability, failover mechanisms, and graceful degradation.

### Key Objectives
1. **Zero system crashes** under 100 concurrent users
2. **99.9% uptime** with automatic recovery
3. **Graceful degradation** when services fail
4. **Memory-safe operation** within t3.micro's 1GB limit
5. **No additional infrastructure cost** (utilize free tiers)

### Relationship to Performance Optimization PRD
- **Performance PRD**: Focuses on *speed* and *cost reduction* (Redis commands, download speed)
- **This PRD**: Focuses on *reliability* and *crash prevention*
- **Shared Goals**: Both reduce Redis usage, both optimize for t3.micro constraints
- **No Conflicts**: This PRD builds upon Performance PRD optimizations

|----------|-----------------|--------|-----------|

## 4. Health Gate System

### 4.1 Specification

**Purpose:** Pre-flight check to reject requests early when system is stressed

**File:** `src/middleware/healthGate.ts` (NEW)

**Logic:**
```typescript
interface HealthGateConfig {
  memoryThreshold: number;      // Default: 0.85 (85%)
  queueDepthThreshold: number;  // Default: 150 jobs
  checkInterval: number;        // Default: 5000ms
  gracePeriod: number;          // Default: 30000ms (30s after startup)
}

interface SystemHealth {
  canAcceptRequests: boolean;
  memoryPercent: number;
  queueDepth: number;
  redisHealthy: boolean;
  mongoHealthy: boolean;
  degradationLevel: 'normal' | 'warning' | 'critical';
}
```

### 4.2 Health Gate Middleware

```typescript
// Pseudocode - actual implementation in src/middleware/healthGate.ts

async function healthGateMiddleware(req, res, next) {
  const health = await getSystemHealth();
  
  // Allow health check endpoints to pass through
  if (req.path.startsWith('/health')) {
    return next();
  }
  
  // Check if system can accept new requests
  if (!health.canAcceptRequests) {
    logger.warn('Health gate rejecting request', {
      memory: health.memoryPercent,
      queue: health.queueDepth,
      level: health.degradationLevel
    });
    
    return res.status(503).json({
      status: 'error',
      code: 'SYSTEM_OVERLOADED',
      message: '🔄 System is busy! Please try again in 1 minute.',
      retryAfter: 60,
      degradationLevel: health.degradationLevel
    });
  }
  
  // Add health info to request for logging
  req.systemHealth = health;
  next();
}
```

### 4.3 Health Status Calculation

| Condition | degradationLevel | canAcceptRequests | Action |
|-----------|-----------------|-------------------|--------|
| memory < 70% AND queue < 100 | `normal` | ✅ true | Process normally |
| memory 70-85% OR queue 100-150 | `warning` | ✅ true | Log warning, reduce concurrency |
| memory > 85% OR queue > 150 | `critical` | ❌ false | Reject new requests |
| Redis disconnected | `critical` | ❌ false | Reject, return cached response |
| MongoDB disconnected | `warning` | ✅ true | Partial service (no persistence) |

## 6. Memory Governor

### 6.1 Specification

**Purpose:** Real-time memory monitoring with automatic protective actions

**File:** `src/utils/memoryGovernor.ts` (NEW)

### 6.2 Memory Thresholds

| Level | Heap Usage | Actions |
|-------|-----------|---------|
| **GREEN** | < 70% | Normal operation |
| **YELLOW** | 70-80% | Log warning, prepare for degradation |
| **ORANGE** | 80-85% | Reduce worker concurrency to 2, clear non-essential cache |
| **RED** | 85-90% | Pause queue, reject new requests, force GC |
| **CRITICAL** | > 90% | Emergency: kill slow jobs, clear all cache |
| **FATAL** | > 95% | Controlled shutdown (PM2 auto-restart) |

### 6.3 Memory Governor Implementation

```typescript
// Pseudocode - actual implementation in src/utils/memoryGovernor.ts

interface MemoryGovernorConfig {
  checkInterval: number;        // Default: 10000ms
  yellowThreshold: number;      // Default: 0.70
  orangeThreshold: number;      // Default: 0.80
  redThreshold: number;         // Default: 0.85
  criticalThreshold: number;    // Default: 0.90
  fatalThreshold: number;       // Default: 0.95
}

class MemoryGovernor {
  private currentLevel: 'green' | 'yellow' | 'orange' | 'red' | 'critical' | 'fatal' = 'green';
  private intervalId: NodeJS.Timer | null = null;
  private worker: Worker | null = null;
  
  start(worker: Worker): void {
    this.worker = worker;
    this.intervalId = setInterval(() => this.check(), this.config.checkInterval);
    logger.info('Memory Governor started');
  }
  
  private async check(): Promise<void> {
    const usage = process.memoryUsage();
    const heapPercent = usage.heapUsed / usage.heapTotal;
    const level = this.calculateLevel(heapPercent);
    
    if (level !== this.currentLevel) {
      logger.warn(`Memory level changed: ${this.currentLevel} → ${level}`, {
        heapUsed: Math.round(usage.heapUsed / 1024 / 1024),
        heapPercent: Math.round(heapPercent * 100)
      });
      
      await this.handleLevelChange(level, heapPercent);
      this.currentLevel = level;
    }
  }
  
  private async handleLevelChange(level: string, heapPercent: number): Promise<void> {
    switch (level) {
      case 'yellow':
        // Just log, prepare for potential issues
        break;
        
      case 'orange':
        // Reduce worker concurrency
        if (this.worker && this.worker.opts.concurrency > 2) {
          this.worker.opts.concurrency = 2;
          logger.warn('Reduced worker concurrency to 2');
        }
        // Clear non-essential caches
        await this.clearNonEssentialCache();
        break;
        
      case 'red':
        // Pause queue
        await this.pauseQueue();
        // Force garbage collection if available
        if (global.gc) {
          global.gc();
          logger.info('Forced garbage collection');
        }
        break;
        
      case 'critical':
        // Kill slow jobs
        await this.killSlowJobs();
        // Clear all cache
        await this.clearAllCache();
        break;
        
      case 'fatal':
        // Emergency shutdown
        logger.error('FATAL: Memory critical, initiating shutdown');
        process.exit(1); // PM2 will restart
        break;
    }
  }
}

export const memoryGovernor = new MemoryGovernor();
```

### 7.3 In-Memory Fallback for Redis

```typescript
// src/services/degradation.service.ts

class InMemoryFallback {
  private rateLimits: Map<string, { count: number; expiry: number }> = new Map();
  private sessions: Map<string, any> = new Map();
  private maxSize = 1000; // Prevent memory leak
  
  // Rate limiting fallback
  checkRateLimit(key: string, limit: number, windowMs: number): boolean {
    const now = Date.now();
    const entry = this.rateLimits.get(key);
    
    if (!entry || entry.expiry < now) {
      this.rateLimits.set(key, { count: 1, expiry: now + windowMs });
      this.cleanup();
      return true;
    }
    
    if (entry.count >= limit) {
      return false;
    }
    
    entry.count++;
    return true;
  }
  
  // Session fallback
  getSession(key: string): any {
    return this.sessions.get(key);
  }
  
  setSession(key: string, value: any, ttlMs: number): void {
    if (this.sessions.size >= this.maxSize) {
      // Evict oldest entries
      const firstKey = this.sessions.keys().next().value;
      this.sessions.delete(firstKey);
    }
    this.sessions.set(key, { ...value, expiry: Date.now() + ttlMs });
  }
  
  private cleanup(): void {
    const now = Date.now();
    for (const [key, entry] of this.rateLimits) {
      if (entry.expiry < now) {
        this.rateLimits.delete(key);
      }
    }
  }
}

export const inMemoryFallback = new InMemoryFallback();
```

### 7.4 Degradation Detection

```typescript
// src/services/degradation.service.ts

interface DegradationState {
  redis: 'normal' | 'degraded' | 'down';
  mongodb: 'normal' | 'degraded' | 'down';
  gemini: 'normal' | 'degraded' | 'down';
  manychat: 'normal' | 'degraded' | 'down';
}

class DegradationService {
  private state: DegradationState = {
    redis: 'normal',
    mongodb: 'normal',
    gemini: 'normal',
    manychat: 'normal',
  };
  
  setServiceState(service: keyof DegradationState, state: 'normal' | 'degraded' | 'down'): void {
    if (this.state[service] !== state) {
      logger.warn(`Service ${service} state changed: ${this.state[service]} → ${state}`);
      this.state[service] = state;
    }
  }
  
  getState(): DegradationState {
    return { ...this.state };
  }
  
  isFullyOperational(): boolean {
    return Object.values(this.state).every(s => s === 'normal');
  }
}

export const degradationService = new DegradationService();

const QUEUE_CONFIG = {
  maxQueueDepth: 200,           // Maximum jobs in queue
  warningQueueDepth: 150,       // Log warning at this level
  backpressureKey: 'queue:backpressure',
  checkInterval: 10000,         // Check every 10 seconds
};

let queueMonitorInterval: NodeJS.Timer | null = null;

/**
 * Start queue depth monitoring
 * CHANGE: Added for backpressure management
 * Reason: Prevent memory exhaustion from unbounded queue growth
 */
export function startQueueMonitoring(): void {
  if (queueMonitorInterval) return;
  
  queueMonitorInterval = setInterval(async () => {
    try {
      const stats = await getQueueStats();
      const totalPending = (stats?.waiting || 0) + (stats?.delayed || 0);
      
      const redis = getRedis();
      
      if (totalPending > QUEUE_CONFIG.maxQueueDepth) {
        await redis.set(QUEUE_CONFIG.backpressureKey, '1', 'EX', 60);
        logger.warn(`Queue backpressure ENABLED: ${totalPending} pending jobs`);
      } else if (totalPending < QUEUE_CONFIG.warningQueueDepth) {
        await redis.del(QUEUE_CONFIG.backpressureKey);
      }
      
      if (totalPending > QUEUE_CONFIG.warningQueueDepth) {
        logger.info(`Queue depth warning: ${totalPending} pending jobs`);
      }
    } catch (err) {
      logger.error('Queue monitoring error:', err);
    }
  }, QUEUE_CONFIG.checkInterval);
  
  logger.info('Queue monitoring started');
}

/**
 * Check if queue is accepting new jobs
 */
export async function canAcceptJob(): Promise<boolean> {
  try {
    const redis = getRedis();
    const backpressure = await redis.get(QUEUE_CONFIG.backpressureKey);
    return backpressure !== '1';
  } catch {
    return true; // Allow on error (fail open for backpressure)
  }
}
```

export const detailedHealthHandler = async (req: Request, res: Response) => {
  try {
    const mongoStatus = isMongoConnected() ? 'connected' : 'disconnected';
    const redisStatus = isRedisConnected() ? 'connected' : 'disconnected';
    
    let queueStats = null;
    try {
      queueStats = await getQueueStats();
    } catch (err) {
      logger.warn('Could not fetch queue stats:', err);
    }

    // NEW: Memory health check
    const memUsage = process.memoryUsage();
    const memoryPercent = (memUsage.heapUsed / memUsage.heapTotal) * 100;
    const isMemoryHealthy = memoryPercent < 85;
    
    // NEW: Queue health check
    const queueDepth = (queueStats?.waiting || 0) + (queueStats?.delayed || 0);
    const isQueueHealthy = queueDepth < 150;
    
    // NEW: Degradation state
    const degradation = degradationService.getState();

    const healthy = mongoStatus === 'connected' 
      && redisStatus === 'connected'
      && isMemoryHealthy
      && isQueueHealthy;

    res.status(healthy ? 200 : 503).json({
      status: healthy ? 'healthy' : 'degraded',
      timestamp: new Date().toISOString(),
      services: {
        mongodb: mongoStatus,
        redis: redisStatus
      },
      queue: {
        ...queueStats,
        depth: queueDepth,
        healthy: isQueueHealthy
      },
      memory: {
        used: Math.round(memUsage.heapUsed / 1024 / 1024) + ' MB',
        total: Math.round(memUsage.heapTotal / 1024 / 1024) + ' MB',
        percent: Math.round(memoryPercent) + '%',
        healthy: isMemoryHealthy
      },
      degradation,
      uptime: process.uptime(),
      
      // NEW: Alert flags for monitoring
      alerts: {
        memoryWarning: memoryPercent > 70,
        memoryCritical: memoryPercent > 85,
        queueWarning: queueDepth > 100,
        queueCritical: queueDepth > 150,
        servicesDown: !healthy
      }
    });
  } catch (error) {
    logger.error('Health check failed:', error);
    res.status(503).json({
      status: 'error',
      message: 'Health check failed'
    });
  }
};

## 13. Risk Assessment

### Technical Risks

| Risk | Probability | Impact | Mitigation |
|------|------------|--------|------------|
| **Health gate too aggressive** | Medium | Medium | Tune thresholds based on load testing |
| **Memory Governor false positives** | Low | Medium | Add grace period after startup |
| **Template scripts lower quality** | Low | Low | Pre-test templates, iterate on feedback |
| **In-memory fallback memory leak** | Medium | High | Implement strict size limits, periodic cleanup |
| **PM2 restart loop** | Low | High | Max restart limit, alert on 3+ restarts |

### Operational Risks

| Risk | Probability | Impact | Mitigation |
|------|------------|--------|------------|
| **Upstash Redis outage** | Very Low | High | Graceful degradation to in-memory |
| **Configuration drift** | Low | Medium | Version control all configs |
| **Alert fatigue** | Medium | Medium | Only alert on critical issues |

### Rollback Plan

**Trigger Conditions:**
- Error rate > 10% for > 5 minutes
- Health check failures > 50% of requests
- Memory crashes resume after deployment

**Rollback Steps:**
1. **Immediate:** `pm2 reload ecosystem.config.js --update-env` (with old config)
2. **Quick:** Revert git commit, rebuild Docker image (< 10 minutes)
3. **Full:** Restore from last known good tag (< 15 minutes)
